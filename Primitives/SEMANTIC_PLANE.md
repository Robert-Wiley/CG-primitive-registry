# Semantic Plane Reference

This file acknowledges the existence of a separate Semantic Plane
used for exploration, synthesis, and relational thinking.

Typical contents of the Semantic Plane include:
- Draft explanations
- Diagrams
- Cross-primitive relationships
- Teaching narratives
- Open questions

Nothing in the Semantic Plane is authoritative.

When a concept matures into a governance primitive,
it must be instantiated using PRIMITIVE_TEMPLATE.md
and recorded in the registry.
